# Report Format

## Template

```markdown
# <week_id>

## 一、本周科研内容：<主题>

### 上周计划完成情况

...

### 本周主要进展

...

### 当前问题与判断

...

## 二、本周阅读论文

本周粗读 N 篇论文，精读 M 篇论文。

清单：

- 粗读：...
- 精读：...

### <论文标题>

来源笔记：...

![title abstract](...)

![pipeline](...)

**摘要：** ...

**我的分析/评价：** ...

## 三、下周计划

1. ...
2. ...
3. ...
```

## Writing Rules

- Use concise Chinese.
- Treat the report as a weekly sync, not a full research note.
- Do not copy full `ReadPaper` notes into the report.
- For papers, follow the paper note faithfully; the user will review in Feishu.
- Include uncertain items as `待确认/待补充`.
- In the research section, explicitly review last week's next-plan completion before describing new work.
- In the paper section, put the rough-read/deep-read count and list before per-paper details.
